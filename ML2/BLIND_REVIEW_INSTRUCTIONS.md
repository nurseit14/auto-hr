# Независимая проверка 50 пар для ML2

В пакете 50 пар IT-резюме и вакансий. Оцените их самостоятельно по текстам и
правилам. Поля для ответов пустые. Ответы другого участника и модели в пакет
не включены.

## Как начать

1. Распакуйте архив целиком в отдельную папку.
2. Откройте `START_REVIEW.html` в Chrome, Edge, Firefox или Safari.
   Для формы не нужны сервер, установка программы или подключение к интернету.
3. Введите своё имя или постоянный псевдоним участника. Используйте его до конца
   проверки, чтобы ответы разных людей не смешались.
4. Прочитайте [полные правила с учебными примерами](ANNOTATION_GUIDELINES.md).

## Как оценивать

Для каждой пары прочитайте резюме и вакансию. Добавьте отдельные требования:
роль и уровень, профильный опыт, технологии, языки и другие явные требования.
Отметьте в названии или объяснении, если навык только желателен.

Для каждого требования заполните категорию, название, точную цитату вакансии,
оценку и объяснение. Для оценок 1–3 скопируйте точную цитату резюме; для 0
оставьте цитату резюме пустой.

| Балл требования | Смысл |
| --- | --- |
| 0 | Недостаточно сведений |
| 1 | Есть прямое подтверждение несоответствия |
| 2 | Есть частичное подтверждение |
| 3 | Требование подтверждается текстом |

Затем отдельно выставьте общую оценку: **0** — недостаточно данных, **1** —
слабое соответствие, **2** — частичное, **3** — хорошее. Общая оценка не равна
среднему баллов требований. Объясните ключевые основания и отметьте, что
завершили проверку пары. Форма проверяет заполнение и цитаты; их смысл
проверяете вы.

Неупомянутый навык неизвестен, а не доказанно отсутствует. Общий стаж не
переносится автоматически на нужную профессию. При ошибках извлечения или
противоречивом тексте укажите проблему в замечаниях.

Для опыта «по настоящее время» используйте **дату, указанную в форме**: она
сохранена для сопоставимости с исходным пакетом. Не заменяйте её датой
заполнения. Остальные сведения оценивайте по сохранённым текстам. Не ищите
старую оценку пары и не обсуждайте ответы с первым участником до завершения
независимой проверки.

## Как сохранить и вернуть ответы

Форма сохраняет черновики в этом браузере на этом устройстве. Перенос архива на
другой компьютер не переносит сохранённые ответы. Регулярно нажимайте
**«Экспортировать ответы»**, особенно перед закрытием браузера или сменой
устройства. Не очищайте данные браузера во время работы.

После проверки всех 50 пар убедитесь, что форма показывает 50 завершённых,
и экспортируйте результат в JSON. Передайте Куату этот файл. Незавершённые
ответы тоже можно экспортировать как черновик; они не считаются готовыми
оценками. При предупреждении, что сохранение в браузере недоступно,
обязательно скачайте ответы перед закрытием страницы.

Если проверка прервалась, продолжайте в той же распакованной папке, в том же
браузере и под тем же именем участника. Для восстановления из скачанного JSON
нажмите **«Восстановить JSON»** и выберите свой файл. Он должен относиться к этому
пакету и вашему имени. Перед заменой уже сохранённых ответов форма предложит
подтверждение; при необходимости сначала экспортируйте текущие черновики.

## Если используется Label Studio

Этот же пакет содержит `tasks.json` и `blind_label_config.xml`. Координатор может
создать **отдельный** проект без предсказаний, установить конфигурацию из XML
и импортировать задания из JSON. Разметчик вручную выделяет требования в тексте
вакансии, заполняет баллы, объяснения и цитаты, затем сохраняет аннотацию.

Для передачи результата нужен полный экспорт **JSON**, сохраняющий
`annotations[].result`. Не используйте JSON-MIN и не добавляйте в этот проект
старые ответы. Выберите один способ работы для всего пакета: браузерную форму
или Label Studio.
